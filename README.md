# びあけん対策ドリル（スマホ向け学習アプリ）

日本ビール検定（びあけん）対策の4択クイズアプリ。素の HTML / CSS / JavaScript だけで動く PWA（ビルド工程・npm 不要）。iPhone の Safari で開いてホーム画面に追加でき、オフラインでも動きます。

## フォルダ構成・ファイル一覧

```
07_勉強アプリ/
├── index.html             … 画面（ホーム / クイズ / 結果）
├── style.css              … デザイン（ビール配色・スマホ最適化）
├── app.js                 … ロジック（出題・採点・復習・進捗・保存）
├── questions.js           … ★問題データ（ここを編集して問題を追加）
├── manifest.webmanifest   … PWA設定（ホーム画面追加用）
├── service-worker.js      … オフライン動作（キャッシュ）
├── icon-180.png           … iPhoneホーム画面アイコン（※gitignore対象・再生成可）
└── README.md              … このファイル
```

## 機能

- **4択クイズ**：1問ずつ出題 → 選択 → 正誤と解説を表示 → 次へ。分野でしぼり込み・シャッフルのON/OFFが可能。
- **復習モード**：間違えた問題を端末に記録し、間違えた問題だけ再出題。正解すると復習リストから自動的に外れます。
- **進捗表示**：ホームに「収録問題数・累計解答数・正答率」、クイズ中に進捗バー、終了後に正答率を表示。
- **保存**：間違い記録と統計はブラウザの localStorage に保存（アプリを閉じても残ります）。「記録をリセット」で全消去。

## 使い方

### パソコンで動作確認する場合
`index.html` をダブルクリックしてブラウザで開けばそのまま動きます。
（※`file://` で開くとオフラインキャッシュ機能＝Service Worker だけは動きませんが、クイズ・復習・記録はすべて動作します。）

### iPhone で使う・ホーム画面に追加する
PWA としてオフライン動作させるには、ファイルを「http / https で配信」する必要があります。いちばん手軽な方法は次の2つです。

**方法A：簡易サーバーで配信（同じWi-Fi内のiPhoneから開く）**
1. Mac のターミナルでこのフォルダに移動して、サーバーを起動：
   ```bash
   cd "07_勉強アプリ"
   python3 -m http.server 8000
   ```
2. Mac の IP アドレスを確認（例：`192.168.1.10`）。
3. iPhone の Safari で `http://192.168.1.10:8000/` を開く。

**方法B：無料ホスティングに置く**
GitHub Pages / Netlify / Cloudflare Pages などにこのフォルダを置けば、URL でどこからでも開けます（このフォルダをそのままアップロードするだけ。ビルド不要）。

**ホーム画面に追加する手順（iPhone / Safari）**
1. 上記のURLを Safari で開く。
2. 画面下の「共有」ボタン（□に↑）をタップ。
3. 「ホーム画面に追加」を選ぶ。
4. 名前（びあけんドリル）を確認して「追加」。
5. ホーム画面のアイコンから起動すると、全画面アプリとして動作し、一度開けばオフラインでも使えます。

## 問題の追加方法（`questions.js` の書き方）

`questions.js` を開き、配列の末尾に問題オブジェクトを追記するだけです（保存後アプリを開き直すと反映）。

```js
{
  id: 15,                       // 一意の番号（既存とかぶらない数字）
  category: "原料",             // 分野：原料 / 製法 / スタイル / 歴史 / 楽しみ方 / その他
  level: 3,                     // 級の目安（3 / 2 / 1）
  question: "問題文をここに書く",
  choices: ["選択肢1", "選択肢2", "選択肢3", "選択肢4"],  // 必ず4つ
  answer: 0,                    // 正解の番号。choices の何番目か（0始まり：1番目=0, 4番目=3）
  explanation: "解説をここに書く"
},
```

ポイント：

- `choices` は必ず4つ。`answer` は 0〜3（0=1番目, 3=4番目）。
- 各問のうしろのカンマ `,` を消さないよう注意。
- 新しい分野名を `category` に書けば、ホームの「分野でしぼる」に自動で追加されます。
- **公式テキストの文章はそのまま転載しないこと**（著作権配慮）。一般的な事実をもとに自分の言葉で作問してください。

## 著作権・データについて

- 同梱のサンプル14問は、ビールに関する一般的な事実をもとに自作したものです。公式テキスト等の文章は転載していません。
- 問題を追加する際も、出典の文章をそのまま写さず、自分の言葉で書き起こしてください。

## メンテナンスメモ

- アプリのファイル（html/css/js）を更新したら、`service-worker.js` 内の `CACHE_VERSION` の数字を上げると、端末側のキャッシュが更新されます。
- `icon-180.png` は `.gitignore` の画像除外ルールにより Git では追跡されません（再生成できる素材のため問題ありません）。アプリの動作には必須ではなく、無くてもホーム画面に追加できます。
